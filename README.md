# Библиотека — информационная система

![Библиотека](images/library.jpg)

*Информационная система для учёта книг, читателей и выдачи литературы.*

## Описание программы

Данный проект представляет собой простую информационную систему **«Библиотека»**.

Программа предназначена для хранения информации о книгах, читателях и контролирования выдачи литературы.

**Основные возможности программы:**

- Добавление новых книг.
- Просмотр списка книг.
- Поиск необходимой литературы.
- Учёт читателей.
- Контроль выдачи и возврата книг.

## Установка

Для запуска проекта необходимо выполнить несколько действий.

**Шаг 1.** Установите Git.

Ссылка: https://git-scm.com/

**Шаг 2.** Склонируйте репозиторий:

```bash

```

**Шаг 3.** Откройте проект в Visual Studio.

**Шаг 5.** Запустите программу.

### Пример работы программы

Пример кода на языке C#:

```csharp
using System;

class Program
{
    static void Main()
    {
        string book = "Война и мир";
        string author = "Лев Толстой";

        Console.WriteLine("Книга: " + book);
        Console.WriteLine("Автор: " + author);
    }
}
```

Результат выполнения:

```text
Книга: Война и мир
Автор: Лев Толстой
```
